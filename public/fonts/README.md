# Local font assets

Special Elite (regular) and JetBrains Mono (regular) are self-hosted so the UI does not depend on a third-party font request. The UI uses Special Elite for display/body and JetBrains Mono for URLs and numeric media metadata.

- Special Elite: Google Fonts, https://fonts.google.com/specimen/Special+Elite. Font downloaded from https://fonts.gstatic.com/s/specialelite/v20/XLYgIZbkc4JPUL5CVArUVL0nhnc.ttf. Apache 2.0 license in Special-Elite-LICENSE.txt.
- JetBrains Mono: Google Fonts, https://fonts.google.com/specimen/JetBrains+Mono. Font downloaded from https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbY2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKxjPQ.ttf. SIL Open Font License in JetBrains-Mono-OFL.txt.
